## Script for archiving the projects and loggin

#### How to use
- Make the script executable by using the command "chmod +x script.sh"
- Run the script by using the command "sh script.sh"
- After running the script, you need to enter the ammount of archives you want to keep
- The script will only keep the last n (entered by the user) and remove the rest


#### Note
The script follows the specific Paths.The paths can be changed in the scriptitself.
